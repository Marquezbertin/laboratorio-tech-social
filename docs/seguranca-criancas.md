# 🛡 Segurança de Crianças e Adolescentes

A proteção de menores é **prioridade máxima** deste projeto social. Todos que interagem com alunos devem seguir estas diretrizes.

## Regras obrigatórias

1. **Never share** dados pessoais de alunos (nome completo, endereço, telefone, escola) publicamente.
2. Todo voluntário que dará aula presencial deve ser aprovado pelo coordenador do projeto.
3. Aulas presenciais devem ocorrer em **locais públicos e autorizados** (escolas, bibliotecas, espaços comunitários).
4. Nunca comunicar-se com menores por canais privados pessoais; use apenas canais oficiais do projeto.
5. Imagens/vídeos de alunos só podem ser publicados com **autorização por escrito** dos responsáveis (LGPD / Estatuto da Criança e do Adolescente).

## LGPD e menores

- Coletamos o mínimo de dados, com consentimento dos responsáveis.
- Dados de menores não são vendidos nem compartilhados com terceiros para marketing.
- Direito de revogar consentimento a qualquer momento.

## Conduta

- Trate todos com respeito e igualdade.
- Denuncie qualquer comportamento inadequado ao coordenador imediatamente.
- Em caso de risco, acione os canais oficiais de proteção (Conselho Tutelar).

## Online

- Use contas institucionais, não pessoais, para interagir com turmas.
- Gravações de aulas devem ser tratadas conforme autorização dos responsáveis.
