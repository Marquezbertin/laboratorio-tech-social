# Ecossistema de Conteúdos — Laboratório Tech Social

## Visão Geral

O Laboratório Tech Social é o **hub central** de um ecossistema de repositórios gratuitos e open source para ensino de tecnologia. Cada repositório é independente e pode ser usado isoladamente.

## Como Usar

### Para professores/voluntários
1. Comece pelo [`guia-do-voluntario.md`](guia-do-voluntario.md)
2. Escolha os módulos das trilhas
3. Use os repositórios complementares para exercícios extras
4. Acompanhe o [`calendario.html`](../site/calendario.html) para organizar as aulas

### Para alunos
1. Inscreva-se em [`inscricao/`](../inscricao/)
2. Escolha sua trilha (crianças ou adolescentes)
3. Baixe os exercícios dos repositórios complementares
4. Participe das aulas ou estude pelo site

### Para instituições
1. Leia o [`plano-pedagogico.md`](plano-pedagogico.md)
2. Entre em contato: bertinmarquez84@gmail.com
3. Reproduza o laboratório gratuitamente
