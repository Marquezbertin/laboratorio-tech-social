# Como Contribuir 🤝

Obrigado por querer tornar este laboratório ainda melhor! Toda contribuição é bem-vinda.

## Tipos de contribuição
- ✍️ Melhorar materiais das trilhas (`trilhas/`).
- 📊 Criar slides, apostilas ou imagens (`materiais/`).
- 🐛 Corrigir erros de código ou texto.
- 💡 Sugerir novos módulos ou projetos.
- 🧑‍🏫 Ser voluntário para dar aulas (ver `docs/guia-do-voluntario.md`).

## Passo a passo (Git)
1. Faça um **fork** deste repositório.
2. Crie uma branch: `git checkout -b minha-melhoria`.
3. Faça suas alterações com clareza.
4. Commit: `git commit -m "Melhora o módulo de Scratch"`.
5. Push e abra um **Pull Request** explicando a mudança.

## Regras
- Mantenha o tom educativo, simples e gratuito.
- Respeite o [Código de Conduta](CODE_OF_CONDUCT.md).
- Para menores: siga `docs/seguranca-criancas.md` (não exponha dados).
- Use licença MIT — conteúdo segue livre e aberto.

## Reportar problemas
Abra uma *issue* com a tag adequada: `bug`, `melhoria`, `nova trilha`, `voluntario`.

Juntos construímos uma tecnologia mais inclusiva! 💙
