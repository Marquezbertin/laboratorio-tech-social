# 📊 Slides Prontos

Apresentações para apoiar as aulas do laboratório. Prontas para usar e fáceis de adaptar.

## Como usar
- Os decks são em HTML com [Reveal.js](https://revealjs.com/) (abre no navegador, sem instalar).
- Para editar, basta alterar o texto entre as tags `<section>`.
- Pressione **F** para tela cheia e **ESC** para o mapa de slides.

## Arquivos
- `aula-01-boas-vindas.html` — deck completo de exemplo (aula de abertura).
- `template-slides.html` — modelo em branco para criar novos decks.

> Dica: você também pode converter Markdown em slides com o Marp ou reveal-md, mas estes decks já funcionam sozinhos.
