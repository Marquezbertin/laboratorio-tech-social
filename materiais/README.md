# 📂 Materiais

Pasta para recursos complementares das aulas: slides, apostilas, imagens, planilhas e templates.

## Organização sugerida
```
materiais/
├── slides/          # Apresentações por módulo
├── apostilas/       # PDFs ou MD impressos
├── imagens/         # Logos, ilustrações do lab
└── templates/       # Modelos de plano de aula, certificados
```

## Identidade visual (sugestão)
- Cores: azul (#38bdf8), rosa (#ff6f61), fundo escuro (#0f172a).
- Tom: acolhedor, lúdico para crianças e profissional para adolescentes.
- Logotipo: em breve (sinta-se à vontade para contribuir!).

## Como usar
Professores podem baixar e adaptar livremente, mantendo o crédito e o caráter gratuito.
