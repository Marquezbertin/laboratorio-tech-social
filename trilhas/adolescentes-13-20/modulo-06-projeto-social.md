# Módulo 06 — Projeto Social de Impacto 🌍

**Duração:** 4+ encontros · **Entregável:** repositório open source publicado.

## Objetivo
Juntar tudo que você aprendeu para criar algo útil para a sua comunidade — e disponibilizar de graça.

## Ideias de projeto
- 🏆 Site de resultados esportivos locais (estilo [Esporte São Pedro](https://esportesaopedro.com.br/)).
- 📚 Portal de aulas gratuitas para crianças da sua escola.
- 🧪 Ferramenta de QA educativa (estilo [Despertar QA](https://www.despertarqa.net/)).
- 🌡 Painel de dados abertos da sua cidade (IoT + nuvem).
- ♻ App de reciclagem ou voluntariado do bairro.

## Roteiro
1. **Problema:** escolha algo que incomoda você ou sua comunidade.
2. **Protótipo:** site, script ou app simples (Módulos 01–05).
3. **Teste (QA):** liste casos de teste e rode (Módulo 03).
4. **Dados:** se fizer sentido, use dados reais (Módulo 04).
5. **Publicar:** GitHub Pages + licença MIT.
6. **Mostra:** apresente para a turma e para a comunidade.

## Template de README do projeto
```markdown
# Nome do Projeto
Problema: ...
Público: ...
Tecnologias: Python / HTML / JS / IoT
Como rodar: ...
Licença: MIT (gratuito e aberto)
```

## Critérios de sucesso
- Resolve (mesmo que simples) um problema real.
- Código aberto e documentado.
- Testado.
- Publicado e acessível gratuitamente.

> Parabéns, você agora é um Maker/Dev que muda comunidades! 🚀
