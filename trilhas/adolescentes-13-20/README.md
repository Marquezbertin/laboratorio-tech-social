# 🧑‍💻 Trilha dos Makers/Devs (13–20 anos)

Bem-vindo ao laboratório dos **Makers/Devs**! Aqui você aprende tecnologia de verdade, com projetos que viram portfólio e impacto social.

Inspirado nos projetos reais do criador deste lab ([QA, dados e web](https://www.despertarqa.net/)), você vai do zero ao projeto open source.

## 🗺 Mapa da trilha

| Módulo | Tema | Entregável |
|--------|------|------------|
| 01 | Python & Lógica | Scripts e exercícios |
| 02 | Desenvolvimento Web | Site responsivo (HTML/CSS/JS) |
| 03 | Qualidade de Software (QA) | Plano de teste + automação básica |
| 04 | Ciência de Dados | Notebook de análise com Python |
| 05 | IoT & Nuvem | Protótipo conectado |
| 06 | Projeto Social | App/site aberto para a comunidade |

## 🎯 Objetivo final

Entregar um **projeto de impacto social** em open source (ex: site para um projeto local, bot de dados do Esporte São Pedro, ferramenta de QA educativa). Publicado no GitHub Pages.

## 📦 Pré-requisitos
- Notebook com Python 3 instalado (ou usar [Google Colab](https://colab.research.google.com/)).
- Conta no [GitHub](https://github.com/).
- Vontade de aprender e errar muito (faz parte!).
