# 🧒 Trilha dos Exploradores (8–12 anos)

Bem-vindo ao laboratório dos **Exploradores**! Aqui a gente aprende tecnologia brincando.
Não precisa saber nada antes de começar. Vamos descobrir, errar, consertar e criar.

> Dica para professores: cada módulo tem duração sugerida de 60–90 min. Veja o [`guia-do-voluntario`](../../docs/guia-do-voluntario.md).

## 🗺 Mapa da trilha

| Módulo | Tema | O que a criança vai fazer |
|--------|------|---------------------------|
| 01 | Pensamento Computacional | Jogos de lógica e quebra-cabeças |
| 02 | Scratch | Criar uma animação ou jogo em blocos |
| 03 | Robótica & IoT | Acender um LED e entender sensores |
| 04 | Primeiro Site | Publicar uma página pessoal em HTML/CSS |
| 05 | Cidadania Digital | Navegar seguro e ser gentil online |

## 🎯 Objetivo final

No último encontro, cada Explorador apresenta um **projeto pessoal** (um jogo, um site ou uma invenção com LED) para a turma e para a família.

## 📦 Pré-requisitos

- Computador ou tablet com internet.
- Conta gratuita no [Scratch](https://scratch.mit.edu/).
- Navegador (Chrome, Firefox, Edge).
- Para o módulo 03: kit básico Arduino/Pico (emprestado pelo lab).

## 🚀 Como começar

1. Abra o [`módulo 01`](modulo-01-pensamento-computacional.md).
2. Faça os desafios propostos.
3. Quando terminar, siga para o próximo módulo.
