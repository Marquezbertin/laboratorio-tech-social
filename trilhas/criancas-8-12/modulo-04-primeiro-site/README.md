# Módulo 04 — Meu Primeiro Site 🌐

Neste módulo você vai criar uma página web e publicá-la de graça no GitHub Pages!

Veja o exemplo completo em [`index.html`](index.html). É só abrir no navegador para ver funcionando.

## Passos
1. Abra o `index.html` em um editor (ou no bloco de notas).
2. Troque o seu nome e a cor favorita.
3. Salve e recarregue no navegador.
4. Com a ajuda do professor, publique no GitHub Pages para o mundo ver! 🌍

## O que você aprendeu
- **HTML:** a estrutura (títulos, textos, botões).
- **CSS:** a beleza (cores, fontes, cantos arredondados).
- **Publicar:** deixar sua criação online, de graça.
