# 📁 Projetos

Esta pasta reúne os **projetos finais** dos alunos e desafios do laboratório.

## Como organizar um projeto aqui
Crie uma subpasta com o nome do projeto:

```
projetos/
└── nome-do-projeto/
    ├── README.md        # O que é, problema, público, tech
    ├── codigo/          # Arquivos do projeto
    └── imagens/         # Fotos ou prints
```

## Exemplos de projetos
- **Placar da Cidade** — site de resultados esportivos locais (inspirado no [Esporte São Pedro](https://esportesaopedro.com.br/)).
- **Despertar Kids** — ferramenta de QA lúdica para crianças (inspirado no [Despertar QA](https://www.despertarqa.net/)).
- **Estação Clima** — sensor IoT + painel na nuvem.
- **Aulas Abertas** — portal de aulas gratuitas do bairro.

## Regras
- Todo projeto deve ser **gratuito** e **open source** (licença MIT).
- Inclua instruções de como rodar.
- Respeite a privacidade (sem dados de menores sem autorização).
